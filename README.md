# GM Research × Investidor10

Portal público: https://gustavomassotti-byte.github.io/gm-investidor10/

## COMO EDITAR O PORTAL

Você não precisa editar o HTML.

### Adicionar PDF
1. Entre em `documentos`.
2. Escolha: `carteiras`, `acoes` ou `fiis`.
3. Clique **Add file / Adicionar arquivo → Upload files / Carregar arquivos**.
4. Arraste o PDF.
5. Clique **Commit changes / Confirmar alterações**.
6. Aguarde a publicação automática.

### Substituir
Exclua a versão antiga e envie a nova. Para manter o mesmo card, use o mesmo nome de arquivo.

### Excluir
Abra o PDF no GitHub → menu de opções → **Delete file / Excluir arquivo** → confirme.

### Organização
- `documentos/carteiras/` — carteiras mensais.
- `documentos/acoes/` — dossiês e relatórios de ações.
- `documentos/fiis/` — dossiês e relatórios de FIIs.

O portal gera a lista automaticamente a partir dos PDFs dessas pastas.
